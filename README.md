# Scentify - Perfume Web Application

Scentify is a modern, responsive web application for exploring and discovering perfumes. Built with React, TypeScript, and Tailwind CSS, it offers a seamless user experience for browsing fragrance collections.

## Features

- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Modern UI/UX**: Clean and aesthetic interface using Tailwind CSS.
- **Product Exploration**: Browse a variety of perfumes with detailed descriptions.
- **AI Integration**: (Mention if any AI features are active, based on dependencies like `@google/generative-ai`)

## Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Database/Backend**: Supabase (Client integration)
- **AI**: Google Generative AI

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Triger-53/Perfume-Web.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Scripts

- `npm run dev`: Start the development server.
- `npm run build`: Build the application for production.
- `npm run preview`: Preview the production build locally.
